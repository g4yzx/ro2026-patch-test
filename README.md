# 葉子仙境 / YZXRO

> 一个基于 **rAthena** 的仙境传说（Ragnarok Online）模拟器整合项目
> 署名：**yzxhome · 葉子仙境**

---

## 这是什么

本仓库是《葉子仙境 / YZXRO》的**游戏补丁更新通道**，只做一件事：

> 让游戏启动器能自动检查并下载最新补丁。

- 仓库里只放**补丁清单**与**补丁包**；
- **完整的游戏客户端不在这里**（体积太大），请从下方网盘链接下载。

## 怎么玩

### 第一次玩（三步）

**第 1 步：下载客户端**（两种任选其一，都能正常玩）

- **V1.0 完整客户端**（已整合好，**推荐**）
  [**点此下载**](https://pan.baidu.com/s/1Ch4yq_oHFXDyX1hJKkRtMg?pwd=ftp3)　提取码：**`ftp3`**
- **纯净基础客户端**（体积小，需要自己再打一次补丁）
  [**点此下载**](https://noxararo.com/downloads/client/2026-09-19_full_client.rar)

**第 2 步：解压**

- 解压到一个**全新的空目录**。不要覆盖旧客户端残留；路径尽量**短、用英文**（例如 `D:\YZXRO\`）。
- 如果你下载的是**纯净基础客户端**，还需要**打一次补丁**（下载 V1.0 完整客户端的可跳过）：
  打开本仓库右侧的 **Releases** 页面，下载最新补丁包（文件名形如 `patch-1.0.1.zip`），
  把补丁包**全部解压覆盖到客户端根目录**，遇到同名文件选「全部覆盖」。
  补丁包里已经包含启动器、配置文件与全部更新内容，覆盖完成即是最新版。

补丁要覆盖到**客户端根目录这一层**，不要多套一层文件夹：

```
D:\YZXRO\                     ← 第 2 步解压出来的客户端根目录
├─ data.grf
├─ Ragexe-2026-02-19_patched.exe
├─ data\  System\  ...
└─ RoLauncher.exe             ← 打补丁后会出现在这一层
```

**第 3 步：双击 `RoLauncher.exe` 开始游戏**

- 启动器是**唯一启动入口**：它会自动检查并更新到最新版本，更新完成后点「开始游戏」。
- 请不要直接运行游戏主程序。
- 启动器已内置服务器地址，**不需要手动修改任何配置文件**。

### 已经在玩的

直接双击 `RoLauncher.exe` 即可 —— 启动器会自动把客户端更新到最新版，**不需要再手动下载补丁包**。

## 怎么注册账号

**不需要去网站注册**，在游戏登录界面就能自助建号。

1. 打开 `RoLauncher.exe`，等它更新完，进入登录界面。
2. **账号**栏填「**你想要的账号名 + `_M` 或 `_F`**」：
   - 想要**男**角色 → 账号名后面加 `_M`（例：`zhangsan_M`）
   - 想要**女**角色 → 账号名后面加 `_F`（例：`zhangsan_F`）
3. **密码**栏填你自己设的密码。
4. 点「登录」——第一次这样登录会**自动创建账号**。

登录成功后会进入角色选择界面，在**那里创建角色**就可以开始玩了。

### 账号名和密码的要求（很重要，请先看）

- **账号名（去掉 `_M` / `_F` 之后）至少 6 位**，只能用**英文字母 + 数字**，不要用中文、空格或符号。
  - ✅ 可以：`zhangsan_M`、`abc123_F`
  - ❌ 不行：`abc_M`（去掉后缀只剩 3 位，太短）、`张三_M`（中文）
- **密码至少 6 位**，建议英文 + 数字混合。

> ⚠️ 名字或密码太短时，登录界面只会提示「**账号或密码错误 / 账号不存在**」，
> 看起来像是密码打错了，其实是长度不够 —— 请先按上面的要求检查一遍。

### 注册一次之后，以后怎么登录

- `_M` / `_F` **只在第一次注册时加**。
- 以后每次登录，**只填账号名，不要再加 `_M` / `_F`**。
  - 例：注册时填的是 `zhangsan_M`，以后登录就填 `zhangsan` + 你的密码。

### 注意

- **性别在注册时就定下来了，之后不能修改**，请先想好再注册。
- 一个账号可以创建多个角色，不需要重复注册。
- 账号名注册成功后**不能更改**。
- **忘记密码无法自助找回**，请联系管理员。

## 常见问题

### 启动器提示「无写入权限」怎么办？

这是**本机安全软件（杀毒 / 安全卫士 / 企业管控）拦截了启动器的更新文件**导致的，**不是客户端问题**。按顺序试：

1. **装到短路径**：把客户端放到 `D:\YZXRO\` 这类**短、英文、有写权限**的目录；不要放在 `C:\Program Files`、桌面、或含中文/空格的深目录。
2. **加白名单**：把 **`RoLauncher.exe` 与整个客户端目录**加入杀毒软件 / 安全卫士的**信任（白名单）**。
3. **重启后再试**：重启电脑后再点一次启动器 —— 部分拦截在重启前不会释放。
4. **仍不行**：直接下载最新**全量客户端**覆盖安装。

> 更新失败时启动器会**自动回滚，并且不写更新状态**，客户端不会被改坏，**可以安全重试**。

### 提示缺少 `msvcr*.dll` / `mfc*.dll`？

安装「微软常用运行库合集（VC++ 2005-2022）」即可。

### 启动后黑屏 / 闪退？

先运行客户端目录里的 `Setup.exe`，改成**窗口化模式**再试。

### 登录不上 / 一直卡在「正在检查更新」？

- 确认本机能正常上网；
- 检查本机防火墙与代理设置（部分代理会拦截游戏流量）；
- 启动器会自动切换加速线路重试，稍等片刻或重开启动器。
