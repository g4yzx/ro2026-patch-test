## 怎么注册账号

**不需要去网站注册**，在游戏登录界面就能自助建号。

1. 打开 `RoLauncher.exe`，等它更新完，进入登录界面。
2. **账号**栏填「**你想要的账号名 + `_M` 或 `_F`**」：
   - 想要**男**角色 → 账号名后面加 `_M`（例：`zhangsan_M`）
   - 想要**女**角色 → 账号名后面加 `_F`（例：`zhangsan_F`）
3. **密码**栏填你自己设的密码。
4. 点「登录」——第一次这样登录会**自动创建账号**。

登录成功后会进入角色选择界面，在**那里创建角色**就可以开始玩了。

### 账号名和密码的要求（很重要，请先看）

- **账号名（去掉 `_M` / `_F` 之后）至少 6 位**，只能用**英文字母 + 数字**，不要用中文、空格或符号。
  - ✅ 可以：`zhangsan_M`、`abc123_F`
  - ❌ 不行：`abc_M`（去掉后缀只剩 3 位，太短）、`张三_M`（中文）
- **密码至少 6 位**，建议英文 + 数字混合。

> ⚠️ 名字或密码太短时，登录界面只会提示「**账号或密码错误 / 账号不存在**」，
> 看起来像是密码打错了，其实是长度不够 —— 请先按上面的要求检查一遍。

### 注册一次之后，以后怎么登录

- `_M` / `_F` **只在第一次注册时加**。
- 以后每次登录，**只填账号名，不要再加 `_M` / `_F`**。
  - 例：注册时填的是 `zhangsan_M`，以后登录就填 `zhangsan` + 你的密码。

### 注意

- **性别在注册时就定下来了，之后不能修改**，请先想好再注册。
- 一个账号可以创建多个角色，不需要重复注册。
- 账号名注册成功后**不能更改**。
- **忘记密码无法自助找回**，请联系管理员。

## 常见问题

### 启动器提示「无写入权限」怎么办？

这是**本机安全软件（杀毒 / 安全卫士 / 企业管控）拦截了启动器的更新文件**导致的，**不是客户端问题**。按顺序试：

1. **装到短路径**：把客户端放到 `D:\YZXRO\` 这类**短、英文、有写权限**的目录；不要放在 `C:\Program Files`、桌面、或含中文/空格的深目录。
2. **加白名单**：把 **`RoLauncher.exe` 与整个客户端目录**加入杀毒软件 / 安全卫士的**信任（白名单）**。
3. **重启后再试**：重启电脑后再点一次启动器 —— 部分拦截在重启前不会释放。
4. **仍不行**：直接下载最新**全量客户端**覆盖安装。

> 更新失败时启动器会**自动回滚，并且不写更新状态**，客户端不会被改坏，**可以安全重试**。

### 提示缺少 `msvcr*.dll` / `mfc*.dll`？

安装「微软常用运行库合集（VC++ 2005-2022）」即可。

### 启动后黑屏 / 闪退？

先运行客户端目录里的 `Setup.exe`，改成**窗口化模式**再试。

### 登录不上 / 一直卡在「正在检查更新」？

- 确认本机能正常上网；
- 检查本机防火墙与代理设置（部分代理会拦截游戏流量）；
- 启动器会自动切换加速线路重试，稍等片刻或重开启动器。
