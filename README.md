## 这是什么

本仓库是《葉子仙境 / YZXRO》的**游戏补丁更新通道**，只做一件事：

> 让游戏启动器能自动检查并下载最新补丁。

- 仓库里只放**补丁清单**与**补丁包**；

## 怎么注册账号

**打开注册页面填一下就行**，不用去论坛，也不用私聊管理员。

### 从哪里打开注册页面

| 入口 | 怎么进 |
| --- | --- |
| **启动器** | 打开 `RoLauncher.exe`，点主界面上的「**注册账号**」 |
| **游戏登录界面** | 点登录框下方的「**注册账号**」 |
| **手机版** | 用手机浏览器打开 <http://ro.yzxhome.cn:8890/register.html> |

> 电脑上点「注册账号」会用**默认浏览器**打开注册页面；填完回到游戏，用新账号登录即可。
> 游戏里自带的注册窗口和这个页面是**同一套**，从哪儿进都一样。

### 页面上要填什么

| 项目 | 要求 |
| --- | --- |
| **账号** | 4~23 位，**英文字母开头**，只能用**字母 / 数字 / 下划线** |
| **密码 / 确认密码** | 6~32 位，两遍要一致 |
| **邮箱** | 填常用的（用于核对身份、找回密码） |
| **性别** | **男 / 女，二选一** |
| **验证码** | 图片上的 4 位数字；看不清就点一下图片换一张 |

点「**注册**」，看到「注册成功」就可以回到游戏，用这个账号登录了。
登录成功后进入角色选择界面，在**那里创建角色**就能开始玩。

### 注意（很重要，请先看）

- **性别在注册的时候就定下来了，之后改不了** —— 注册前先想好，这是游戏本身的限制。
- **账号名**要**英文字母开头**，只能用**字母 / 数字 / 下划线**，不要用中文、空格或特殊符号。
  - ✅ 可以：`zhangsan`、`abc123`、`li_wei`
  - ❌ 不行：`张三`（中文）、`1abc`（数字开头）、`ab`（太短）
- **密码至少 6 位**，建议英文 + 数字混合。
- 一个账号可以创建**多个角色**，不需要重复注册；账号名注册成功后**不能更改**。
- **忘记密码请联系管理员**（玩家群号见上方）。

## 常见问题

### 启动器提示「无写入权限」怎么办？

这是**本机安全软件（杀毒 / 安全卫士 / 企业管控）拦截了启动器的更新文件**导致的，**不是客户端问题**。按顺序试：

1. **装到短路径**：把客户端放到 `D:\YZXRO\` 这类**短、英文、有写权限**的目录；不要放在 `C:\Program Files`、桌面、或含中文/空格的深目录。
2. **加白名单**：把 **`RoLauncher.exe` 与整个客户端目录**加入杀毒软件 / 安全卫士的**信任（白名单）**。
3. **重启后再试**：重启电脑后再点一次启动器 —— 部分拦截在重启前不会释放。
4. **仍不行**：直接下载最新**全量客户端**覆盖安装。

> 更新失败时启动器会**自动回滚，并且不写更新状态**，客户端不会被改坏，**可以安全重试**。

### 提示缺少 `msvcr*.dll` / `mfc*.dll`？

安装「微软常用运行库合集（VC++ 2005-2022）」即可。

### 启动后黑屏 / 闪退？

先运行客户端目录里的 `Setup.exe`，改成**窗口化模式**再试。

### 登录不上 / 一直卡在「正在检查更新」？

- 确认本机能正常上网；
- 检查本机防火墙与代理设置（部分代理会拦截游戏流量）；
- 启动器会自动切换加速线路重试，稍等片刻或重开启动器。
